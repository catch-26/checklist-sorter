# Formatted release differences

These text patches compare the exact JavaScript bundles after **presentation-only formatting** with the TypeScript JavaScript AST printer. Minified variable names and bundler layout can still cause noisy diffs. The original bytes and authoritative history are in the Git tags. The adjacent manifest diffs are produced from unmodified manifest bytes. For added/removed files, consult `git diff --stat <older-tag> <newer-tag>`; those files are not duplicated in this directory.

Each patch corresponds to the two version tags in its name. Formatted output is not added to release tags and is not claimed to be original source code.
